# wetwaresuite tutorials

Hands-on guides to the suite. Every example was run against the real binaries: the all-in-one `wetwaresuite` or the per-app programs like `wetwaresuite-image`, which share the same commands. Everything is a command: the desktop window calls the same commands as the command line, scripts and Claude.

- [The window (GUI)](gui.md): double-click any app to open its window; open files, find any action by typing, fill in simple forms, paint with a mouse or pen, send work to another app and pick it up from the inbox, undo, Simple and Advanced modes (everything is free), text size; works offline with no graphics card.
- [Getting started](getting-started.md): build from source, find commands with `list` and `help`, write arguments, and understand document ids and undo.
- [Headless and batch](headless-and-batch.md): batch scripts with variables and comments, shell loops, CI and cron, exit codes.
- [The apps](apps.md): which app does what, installing only the ones you need, building only some.
- [Workflows](workflows.md): moving work between apps step by step: a texture from image onto a model and into a game, a cad part sculpted and printed, music for a video, a logo on a poster.
- [Updates](updates.md): how installed copies update themselves once a day (checked downloads, swapped in place, open apps keep running), what each kind of install does, checking and installing by hand, cron, Claude, and turning it off.
- [Offline editions](offline-editions.md): everything on a USB stick (1 to 256 GB) with fonts, starter files, materials and world maps; install with no internet.
- [Using wetwaresuite with Claude (MCP)](mcp.md): connect Claude Code or Claude Desktop, what Claude sees, example prompts, troubleshooting.
- [Connecting an AI (optional)](ai-connect.md): `hub connect` sets up Claude Desktop and Claude Code in one command (with backups, `--dry-run` and `--remove`); `wetwaresuite mcp --http` serves the tools over HTTP to another computer, with a token.
- [Working offline](offline.md): everything works with no internet and no AI; every feature that could touch a network, and how to keep it offline; building and installing from a USB stick.
- [Docker (optional)](docker.md): run the suite in a container, one-off commands on a mounted folder, or as an HTTP MCP server.
- [Photo](photo.md): resize folders for the web, fix dark photos, crop, rotate, frame, effects, and retouching (healing brush, seamless clone, remove objects).
- [Paint](paint.md): brush strokes with tablet pressure, presets, layers, blend modes, fills, saving `.ora`.
- [Vector](vector.md): drawing shapes and paths, styling, SVG in and out, a full logo.
- [Blueprint](blueprint.md): floor plans with walls, doors and dimensions printed to scale as PDF, opening and measuring DXF files, part drawings.
- [3D view](3d-view.md): turn any cad part, model, sculpt, scan fit or print around in the window, and the same angles from the command line and Claude with `app.view`.
- [CAD](cad.md): parametric parts with expressions, holes, patterns, booleans, fillets, chamfers and shells; a bracket you resize by changing one number, STEP and STL in and out, measuring.
- [Convert](convert.md): images, SVG, audio, video, office documents and markup, one file or a whole folder.
- [Asset forge](forge.md): game assets: models to glb with the right up axis, scale and LODs, Aseprite-style animated sprites (.aseprite, sheets with Aseprite JSON, Godot SpriteFrames, GIF), sprite sheets and atlases, tileable textures and normal maps, pixel art.
- [Audio](audio.md): clean up a voice recording to podcast loudness, build an episode from music and voice tracks with ducking and fades, batch-normalize samples, spectrograms, pitch and tempo changes.
- [Playback](playback.md): hear clips, project mixes, songs and video edits through your speakers from the window, the command line, scripts and Claude: pause, seek, loop, volume and output devices.
- [Office](office.md): a budget spreadsheet with formulas and a chart, CSV cleanup with VLOOKUP, a report exported to PDF, a slide deck from bullet points, merging and splitting PDFs.
- [Slicer](slicer.md): 3D models to G-code: printer and filament presets, gyroid and cubic infill, brim, column and tree supports, several parts on one bed, layer previews, parts from cad.
- [Scan fit](fit.md): car parts and mounts that fit a phone 3D scan: clean up a Polycam/Scaniverse scan, fit planes, cylinders, circles and curves to it, then a phone mount, gauge pod, switch panel and speaker ring on a curved dash, clamps and a GoPro mount on a roll bar, trim strips, your own plates and blocks, gap checks, test slices and projects you can rebuild.
- [Layout](layout.md): print layout: an event poster, a tri-fold flyer, business cards 10-up, a booklet from Markdown, preflight and print PDFs with bleed and crop marks.
- [Cut](cut.md): video editing like Premiere or Resolve: linked tracks, ripple/roll/slip/slide, razor, insert and overwrite, markers, nests, speed and freeze frames, keyframes, colour wheels and LUTs, chroma key, titles and captions, a loudness-matched mix, export presets; plus quick trims, joins and GIFs.
- [Capture](capture.md): screenshots of a screen, monitor or region, screen recordings with a microphone, webcam snapshots, OBS-style scenes (screen, window, webcam, image, text) with start/stop recording, and how Claude looks at your screen.
- [Toolkit](toolkit.md): identify any file from its contents, hex dumps, the standalone `wetwaresuite-toolkit`.
- [Library](library.md): index an asset drive, tag and rate, find duplicates and similar images, smart collections, thumbnails and contact sheets, asking Claude to find files.
- [Levels](levels.md): game levels and tilemaps: caves, dungeons and overworlds from a seed, auto-tiling (4-bit, blob and Tiled Wang sets), animated tiles, painting and stamping, entities with properties, collision with slopes, worlds of several maps, Tiled TMX/TMJ, Godot scenes, LDtk, JSON and CSV.
- [Automate](automate.md): scripts with variables, pipelines over folders, watch folders that process dropped files, the Python client, cron and Task Scheduler, pipelines from Claude.
- [Model](model.md): polygon modeling like Blender: edit mode with extrude, inset, bevel, loop cut and knife; a table with mirror and bevel modifiers, a box-modelled mug with subdivision surface, windows cut by a boolean, UV unwrap and textures, a bouncing animation; OBJ, glTF, FBX and STL out.
- [Sculpt](sculpt.md): a creature head from a sphere with mirrored strokes, a cad part made organic and sent to the slicer, retopology and LODs for games, relief tiles from heightmaps, aiming strokes on a preview.
- [Beats](beats.md): music making: generate a beat from a genre and key, program drums on a step grid, bass and chords in the piano roll, synth sound design and effects, your own samples, MIDI in and out, stems and mastering.
- [Animate](animate.md): 2D and 3D animation: a bouncing ball with easing and squash, a logo sting, a cutout rig on bones, hand-drawn cels with onion skin, a 3D turntable; GIFs, sprite sheets with JSON atlases, PNG sequences and video.
- [Render](render.md): 3D scenes and pictures: a model to a picture in one command, a still life in metal, glass and textures, studio product shots on transparent backgrounds, sunsets, cad parts, turntable GIFs and MP4s.
- [Circuit](circuit.md): electronics from schematic to fab: an LED board, a 555 blinker to Gerbers, an Arduino Nano carrier with ground pours, hand routing, KiCad netlists, simulating an RC filter.
- [Flash](flash.md): put firmware on Arduino, ESP32/ESP8266 and STM32 boards headless: list and identify serial ports, detect a board, inspect a HEX/BIN/ELF/ESP image, flash and verify with the built-in bootloader protocols (or avrdude/esptool/stm32prog), a serial monitor and send, and simulated boards for trying it all with no hardware.
- [Board](board.md): whiteboards and diagrams: a flowchart from Mermaid, a hand-drawn architecture sketch, sequence diagrams, mind maps from an outline, a retro wall of sticky notes, Excalidraw and draw.io in and out.
- [PDF editor](pdf.md): an Acrobat-style editor: read and search PDFs, change their text, highlight, notes, drawing, white-out and true redaction, pictures and signatures, form filling, and page changes.
- [Notes](notes.md): an Obsidian-compatible Markdown vault from the command line: meeting notes from templates, daily notes, tasks with due dates, ranked search, backlinks and rename-safe wikilinks, a link graph, HTML/PDF and a static site.
- [Maps](maps.md): offline maps and GIS: a world map coloured from a CSV, distances and UTM coordinates, buffers and heatmaps of places, GPX hike stats and elevation profiles, GeoTIFFs and world files, format conversion, point-in-polygon and spatial joins, offline street maps from map packs, OpenStreetMap tiles.
- [Type](type.md): font design: a display font drawn from shapes and SVG, accented letters from components, a font from your handwriting, opening, proofing, subsetting and converting TTF/OTF/WOFF, bold and oblique styles, kerning.
- [Share](share.md): share a folder with a phone or laptop in one command, live-sync a code project between machines, send files, go over the internet with cloudflared or tailscale, and drive it from Claude.
- [Calc](calc.md): a calculator for everything: exact fractions and huge whole numbers, percentages, scientific functions, programmer mode with hex, binary and bit operators, unit conversion, statistics and a line of best fit, solving equations and systems, derivatives and integrals, graphs as PNG, variables, your own functions, memory and history.
- [Code](code.md): an editor and IDE for 38 languages: a file tree, tabs, highlighting, an outline, find and replace across a project, go to line, Run and Build with the compilers already on your computer, clickable errors, and git (stage, commit, history, branches).
- [Files](explorer.md): a file manager where everything can be undone: copy, move, rename many at once, delete to the trash and restore, find files by name, contents, size or age, what takes up space, duplicates, checksums, and zip, tar and tar.gz archives.
- [Terminal](terminal.md): your shell inside the suite: terminals that keep their folder and variables, history, Tab completion, stopping a command, typing answers into a running program, and one-off commands for scripts and Claude.
- [Monitor](monitor.md): what your computer is doing: processor per core, memory, disks, network speed, battery, every running program with filtering and ending, and charts of processor and memory use.
- [Clock](clock.md): world clock and time-zone conversion, timers you can pause, a stopwatch with laps, saved alarms, a calendar with week numbers, days between dates and working days.
