## download

| your computer | get this | then |
| --- | --- | --- |
| **windows** 10/11 | `wetwaresuite-windows-x64-setup.exe` | double-click, next, install. start menu gets every app, plus an uninstaller |
| **macOS** (apple silicon) | `wetwaresuite-macos-arm64.dmg` | open it, drag wetwaresuite into Applications |
| **linux**, any distro | `wetwaresuite-linux-x86_64.AppImage` | `chmod +x` it (or properties > allow executing), double-click |
| **ubuntu / debian / mint** | `wetwaresuite-linux-amd64.deb` | double-click, or `sudo apt install ./wetwaresuite-linux-amd64.deb` |

no install wanted? the `.zip` for your OS runs straight from the folder.

first run: the builds aren't code-signed yet. windows: "More info" then "Run anyway". macOS: right-click the app, Open, then Open again.
